# 桌面反畸变标定模式

此模式实时捕获当前显示器，并通过 GPU 给整个桌面施加可调的预变形。用于初步补偿固定观看位置下，弯曲镜面产生的桶形或枕形畸变。

## 安全设计

- 启动时默认为“安全旁路”：覆盖层透明，不改变桌面。
- 按 `Esc` 可立即隐藏覆盖层并退出主进程。
- 程序会尝试注册 `Ctrl+Alt+Q`；若被系统占用，仍有 `Esc`、`Ctrl+Shift+Alt+F12` 和托盘退出。
- `Ctrl+Alt+B` 随时启用或旁路反畸变。
- 系统托盘图标右键菜单中提供“安全退出”。
- 渲染器失联、崩溃、捕获停止或 WebGL 丢失时，主进程先隐藏覆盖层，再自动退出。
- 标定模式连续 15 分钟没有快捷键操作会自动退出。
- 如果紧急退出快捷键和托盘都无法创建，程序拒绝显示覆盖层。

覆盖层始终鼠标穿透，因此不会阻止操作真实桌面。

## 启动

双击 `start-undistort.bat`。启动后屏幕右侧会出现“桌面反畸变控制台”，此时仍是安全旁路。点击控制台中的“启用反畸变”才会接管桌面画面。

控制台提供主曲率、边角曲率、缩放和畸变中心的可点击按钮；也可以显示/隐藏网格、保存参数、重置旁路或立即退出。关闭控制台窗口等同于安全退出整个程序。

## 标定快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Esc` | 紧急退出 |
| `Ctrl+Alt+Q` | 安全退出（未被其他软件占用时） |
| `Ctrl+Alt+B` | 启用/旁路反畸变 |
| `Ctrl+Alt+↑ / ↓` | 调整主曲率 `k1` |
| `Ctrl+Alt+PageUp / PageDown` | 调整边缘高阶曲率 `k2` |
| `Ctrl+Alt+← / →` | 调整画面缩放，处理裁边或黑边 |
| `Ctrl+Alt+W / A / S / D` | 移动畸变中心 |
| `Ctrl+Alt+G` | 显示/隐藏标定网格 |
| `Ctrl+Alt+P` | 保存当前参数 |
| `Ctrl+Alt+0` | 重置参数并切回安全旁路 |
| `Ctrl+Alt+M` | 移动到鼠标所在显示器 |
| `Ctrl+Alt+H` | 显示帮助 |

如果显卡驱动或其他软件占用了 `Ctrl+Alt` 组合，可使用已经并行注册的后备键：

| 后备快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+F1 / F2` | 减小/增加 `k1` |
| `Ctrl+Shift+F3 / F4` | 减小/增加 `k2` |
| `Ctrl+Shift+F5 / F6` | 缩小/放大画面 |
| `Ctrl+Shift+F7 / F8` | 中心左移/右移 |
| `Ctrl+Shift+F9 / F10` | 中心下移/上移 |
| `Ctrl+Shift+F11` | 显示/隐藏网格 |
| `Ctrl+Shift+Alt+F12` | 第三个独立退出快捷键 |

## 第一次调整建议

1. 把眼睛或摄像头固定在最终观察位置。
2. 启动程序，在控制台点击“启用反畸变”；默认会显示青色网格。
3. 观察镜子中的网格，先点击“主曲率”的 `−/＋`，让边线整体变直。
4. 只有四个角仍然弯曲时，再调整“边角曲率”。
5. 调整画面缩放，避免边缘内容被裁掉。
6. 如果上下左右弯曲不对称，用方向按钮移动畸变中心。
7. 满意后隐藏网格并点击“保存参数”。

参数保存在本机 Electron 配置中，下次启动会自动读取，但仍然从安全旁路状态开始。

## 模型边界

当前版本采用径向多项式：

```text
r² = x² + y²
scale(r) = 1 + k1·r² + k2·r⁴
(x', y') = scale(r) · (x, y)
```

它适合大致中心对称的镜面曲率。如果镜子四个角各自的形状明显不同，下一步需要拍摄镜面中的标定网格，升级为控制点网格或薄板样条映射。
