Vervormde Skerm v1.0.0（Windows x64 便携版）
================================================

无需安装 Node.js，也无需安装本软件。请先完整解压 ZIP，再运行程序。

反畸变模式（默认）
------------------
双击 VervormdeSkerm.exe。
程序会显示桌面反畸变覆盖层和一个控制面板，可调节中心、范围、强度和椭圆比例。

黑洞模式
--------
双击“Start Black Hole.cmd”。

安全退出
--------
1. 按 Esc 立即退出。
2. 反畸变模式可点击控制面板中的“安全退出”。
3. 系统托盘图标菜单中也有退出项。
4. F12 是备用强制退出键。
5. 如果控制面板失联，反畸变覆盖层会自动旁路并退出。

注意事项
--------
- 本版本未进行代码签名，Windows SmartScreen 可能在首次启动时给出提示。
- 默认只在本机显卡上实时处理桌面画面，不上传屏幕内容。
- 多显示器环境当前覆盖主显示器。
